# JUNSHU Security Open-Source Visual Identity

This document defines the temporary visual identity used by the JUNSHU Security GitHub profile. It is not a declaration of final corporate trademark artwork.

## Brand Position

- **Primary tagline:** The Security Control Plane for AI Agents
- **Secondary description:** Open-source security infrastructure for agents, tools, MCP, and autonomous runtime.
- **Operating principle:** Observe. Understand. Decide. Control.
- **Technical idea:** Security at the Point of Execution.

## Visual Concept

The mark represents a controlled pivot inside a connected security graph:

- the vertical axis represents runtime continuity;
- the horizontal axis represents policy balance and judgment;
- the center node represents the point of security decision;
- surrounding nodes represent identity, context, tools, and graph relationships.

It intentionally avoids generic shield, lock, skull, mask, and hacker imagery.

## Usage

- Keep clear space around the mark equal to the diameter of its center node.
- Prefer the supplied light and dark SVG assets without recoloring.
- Do not imply certification, product maturity, customer adoption, or official partnership.
- Do not use the mark to impersonate JUNSHU Security or endorse unrelated products.
