# JUNSHU Security Visual Identity

This document defines the JUNSHU Security visual identity used by the official GitHub profile. The supplied assets are derived from the approved Figma Logo System.

## Brand Position

- **Brand position:** Open Agent Runtime Security Platform
- **Primary tagline:** Security at the Point of Execution.
- **GitHub bio:** Securing AI agents where they actually execute.
- **Developer one-liner:** JUNSHU observes, understands and controls what AI agents actually do.
- **Secondary description:** Open-source security infrastructure for AI agents, coding agents, MCP, tools, and autonomous runtime.
- **Operating principle:** Observe. Understand. Decide. Enforce.
- **Technical idea:** A security control plane for AI agents.

## Visual Concept

The mark represents observation and enforcement meeting on a controlled security axis:

- the cyan upper path represents **Observe**;
- the blue vertical path represents the runtime **Axis**;
- the violet lower path represents **Enforce**;
- the ink center represents the point of security **Decision**.

It intentionally avoids generic shield, lock, skull, mask, and hacker imagery.

## Usage

- Keep the mark's proportions unchanged and preserve adequate clear space.
- Use `avatar.svg` or `avatar.png` for square profile placements.
- Use the supplied light and dark hero assets without recoloring their marks.
- Do not stretch, rotate, recolor, outline, or place the mark at low contrast.
- Do not imply certification, product maturity, customer adoption, or official partnership.
- Do not use the mark to impersonate JUNSHU Security or endorse unrelated products.
